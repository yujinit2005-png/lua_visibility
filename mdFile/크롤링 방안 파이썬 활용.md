# 브라우저 팝업 크롤링 (내장 뷰어 실측) 연동 계획

대표님께서 요청하신 "내장 뷰어 실측 버튼 클릭 시 브라우저 팝업을 시크릿 모드로 띄워 텍스트를 크롤링하는 기능"을 구현하기 위한 계획서입니다.

## User Review Required
> [!IMPORTANT]
> **브라우저 보안 한계 및 로컬 API 서버 구동 필요**
> 현재 화면에 떠 있는 웹(React) 프론트엔드 단독으로는 "시크릿 모드 창 띄우기" 및 "다른 도메인(ChatGPT 등) 화면 글자 읽어오기"가 보안 정책(CORS 및 Same-Origin Policy)상 **절대 불가능**합니다.
> 
> 이를 해결하고 파이썬의 강력한 자동화(Playwright)를 그대로 이용하려면, **로컬 파이썬 API 서버(Flask)**를 백그라운드에 띄워두고, 웹 화면에서 버튼을 누르면 파이썬 서버로 신호를 보내 파이썬이 브라우저 창을 띄워 크롤링한 뒤 웹으로 결과를 돌려주는 방식으로 구현해야 합니다. 이 방식에 동의하시는지 확인 부탁드립니다.

## Proposed Changes

### 1. 파이썬 로컬 API 서버 구축 (`c:\1.RuaCompany\lua_visibility_engine\lua_visibility\api_server.py`)
- `Flask`와 `Flask-CORS`를 사용하여 가벼운 로컬 API 서버를 구축합니다.
- `/api/verify` 엔드포인트를 만듭니다.
- 프론트엔드에서 신호가 오면, 기존 `web_verifier.py`의 로직을 활용하여 **시크릿 모드(Incognito) 브라우저**를 팝업(Headful)으로 띄웁니다.
- 질문을 검색하고 렌더링이 완료될 때까지 기다렸다가, 답변을 추출(크롤링)한 뒤 팝업을 닫고 결과를 웹으로 반환합니다.

### 2. 프론트엔드 연동 (`WebVerificationModal.tsx`)
- 기존에 iframe을 띄우던 '내장 뷰어 실측' 버튼의 동작을 변경합니다.
- 버튼 클릭 시 "크롤링 중..." 상태를 표시하고, 로컬 파이썬 API(`http://localhost:5000/api/verify`)로 요청을 보냅니다.
- 응답받은 크롤링 텍스트를 해당 행의 '웹 UI 수집 원문 (크롤링 결과)' 컬럼에 자동으로 채워넣습니다.

## Verification Plan
1. 파이썬 서버 스크립트 작성 후 사용자에게 실행 방법을 안내합니다 (`pip install flask flask-cors` 및 서버 실행).
2. 웹 화면에서 실측 버튼을 눌렀을 때, 실제로 파이썬 기반의 시크릿 브라우저 창이 뜨고 결과가 웹 화면 격자에 채워지는지 확인합니다.

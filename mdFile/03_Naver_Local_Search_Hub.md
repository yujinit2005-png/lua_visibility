# 03. 네이버 지역검색 API Hub 연동 (Naver Local Search Hub)

## 📌 개요
네이버 지역검색(Naver API Hub)은 자연어 형태의 복잡한 문장을 그대로 전달할 경우, 단어별 OR 매칭으로 인해 엉뚱한 업종(베이커리, 피부과, 치과 등)이 노출되거나 0건이 반환되는 특성이 있습니다. 이를 해결하기 위해 **스마트 엔티티 쿼리 추출 알고리즘**을 도입하였습니다.

---

## 🧠 스마트 엔티티 쿼리 추출 알고리즘

### 1. 3대 핵심 엔티티 조합 원칙
1. **지역명 (Region)**: 시/도 및 구/동 명칭 (예: `청주`, `강서동`, `흥덕구`)
2. **질환/치료명 (Disease/Treatment)**: `허리디스크`, `척추`, `관절`, `추나요법`, `도수치료` 등
3. **병원 유형 (Hospital Type)**: `한방병원`, `한의원`, `내과`, `정형외과`, `병원` 등

### 2. 변환 예시

| 원문 질문 | 정제 후 실제 네이버 검색 쿼리 | 네이버 1위 검색 결과 |
|---|---|---|
| `청주 강서동 근처 척추 관절 한방병원 어디 있어?` | **`청주 강서동 척추 한방병원`** | **`청주필한방병원`** (건강,의료>한방병원) |
| `청주에서 허리디스크 치료 잘하는 한방병원 어디야?` | **`청주 허리디스크 한방병원`** | **`청주자생한방병원`** (건강,의료>한방병원) |
| `충북 청주 허리디스크 비수술 한방병원 알려줘` | **`충북 허리디스크 한방병원`** | **`청주자생한방병원`** (건강,의료>한방병원) |

---

## 📝 수집 답변 상단 검색 쿼리 헤더 명시

수집된 네이버 답변 텍스트의 최상단에 실제 던져진 쿼리 정보가 항상 기록됩니다:

```text
네이버 지역검색(NAVER API HUB) 실측 결과입니다.
📌 원문 질문: 청주 강서동 근처 척추 관절 한방병원 어디 있어?
🔍 실제 검색 쿼리: '청주 강서동 척추 한방병원'
📊 총 검색 결과: 5건 중 상위 2건

[1] 
🏥 병원명(타이틀): 청주필한방병원
🌐 홈페이지(링크): http://cheongju-philhospital.com
📞 전화번호: 043-000-0000
📍 주소: 충청북도 청주시 흥덕구 강서동 483 BYC빌딩 5층
🏷️ 카테고리 및 매칭 키워드: 건강,의료>한방병원 | 청주, 강서동, 척추, 한방병원
📝 설명: 척추관절 비수술 한방 치료 전문
```

---

## 🔁 2차 자동 재검색 (Fallback)
1차 검색 결과가 0건일 경우, 시스템이 자동으로 **`[지역 + 병원유형]`** (예: `용인 내과`)으로 2차 재검색을 수행하여 데이터 누락을 방지합니다.

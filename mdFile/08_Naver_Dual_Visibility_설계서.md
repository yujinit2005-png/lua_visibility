## 2. 네이버 로컬 가시성 (Naver Dual) 핵심 구조

> **"플레이스 노출 경쟁력과 콘텐츠 점유 경쟁력을 이중(Dual) 측정합니다."**

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [A] 네이버 플레이스 점유율 (API)       │ [B] 네이버 콘텐츠 바이럴 점유율 (크롤링)        │
│ "지도 영역에서 우리 병원이 보이는가?"  │ "블로그·웹문서에서 우리 병원이 점유하는가?"     │
│ ➔ 스마트플레이스 지도 순위 (SEO 최적화)│ ➔ 블로그, 카페, 제3자 언급 (바이럴 마케팅)     │
├────────────────────────────────────────┴───────────────────────────────────────────────┤
│ [C] Naver Dual Position Matrix (2x2 매트릭스)                                          │
│ ➔ Local Strong / Market Leader / Low Visibility / Content Strong 진단 및 액션 플랜     │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [D] NAVER LOCAL SHARE OF VOICE (경쟁사 비교)                                           │
│ ➔ 주요 경쟁병원 대비 Place vs Content 가로 Bar 비교 분석                               │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 세부 영역별 상세 설계 명세

### [A] 네이버 플레이스 점유율 (Place SOV)
> **핵심 질문:** *"환자가 지역+진료 키워드로 검색했을 때 지도 영역에서 우리 병원이 얼마나 보이는가?"*

1. **점수 및 판정 체계**:
   - **산출 방식**: 전체 진단 키워드 중 지도 영역 상위권(Top 10 내)에 진입한 비율 및 순위 가중치
   - **상태 판정**: `80% 이상: EXCELLENT` / `60~79%: GOOD` / `40~59%: MODERATE` / `40% 미만: NEEDS IMPROVEMENT`
   - **예시**: `72% · GOOD`

2. **5대 핵심 KPI 카드**:
   - **측정 키워드**: 총 `50개`
   - **Top 3 진입**: `18개` (지도 1페이지 최상단 고정 노출)
   - **Top 5 진입**: `31개` (지도 1페이지 노출)
   - **Top 10 진입**: `36개` (지도 2페이지 이내 노출)
   - **미노출**: `14개` (10위권 밖 또는 지도 결과 없음)

3. **주요 키워드별 플레이스 순위 막대 그래프**:
   - `청주 한방병원` ➔ **2위** (상위 노출)
   - `청주 허리치료` ➔ **4위** (상위 노출)
   - `청주 추나요법` ➔ **3위** (상위 노출)
   - `청주 교통사고 한방병원` ➔ **9위** (경합)
   - `청주 척추관협착증` ➔ **미노출** (개선 필요)

4. **핵심 요약 태그**:
   - `📍 지도에서 얼마나 자주, 얼마나 위에서 발견되는가`

---

### [B] 네이버 콘텐츠 바이럴 점유율 (Content SOV)
> **핵심 질문:** *"검색결과의 블로그·웹문서에서 우리 병원 관련 콘텐츠가 얼마나 점유하고 있는가?"*

1. **점수 및 판정 체계**:
   - **산출 방식**: 네이버 통합검색 상위 노출 콘텐츠(블로그, 카페, 지식iN, 웹문서) 중 당사 병원 관련 콘텐츠 점유율
   - **상태 판정**: `70% 이상: MARKET LEADER` / `50~69%: GOOD` / `30~49%: NEEDS IMPROVEMENT` / `30% 미만: CRITICAL`
   - **예시**: `41% · NEEDS IMPROVEMENT`

2. **5대 핵심 KPI 카드**:
   - **분석 키워드**: 총 `50개`
   - **분석 검색결과**: 총 `500건` (키워드당 상위 10건 스캔)
   - **자사/병원 공식 콘텐츠**: `86건` (17.2%)
   - **제3자 언급 콘텐츠**: `37건` (7.4%) (환자 후기, 커뮤니티, 언론 보도)
   - **경쟁병원 관련 콘텐츠**: `177건` (35.4%)

3. **콘텐츠 구성 비율 도넛 차트**:
   - 🔵 **병원 공식 콘텐츠**: 17% (86건)
   - 🟠 **블로그/웹문서**: 34% (170건)
   - 🟢 **제3자 언급**: 7% (37건)
   - 🔴 **경쟁병원 콘텐츠**: 35% (177건)
   - ⚪ **기타 일반 정보**: 7% (30건)

4. **핵심 요약 태그**:
   - `📄 블로그·웹문서·제3자 언급에서 우리 병원이 얼마나 점유되는가`

### [C] Naver Dual Position Matrix (2x2 사분면 진단)

```
플레이스 점유율 (Y축)
  ▲
  │  [Local Strong]             │  [Market Leader]
높음 │  • 플레이스 우수           │  • 플레이스 & 콘텐츠 모두 장악
  │  • 콘텐츠 장악력 부족       │  • 시장 선도 병원
  │    (청주필한방병원: 72%, 41%)│
──┼─────────────────────────────┼───────────────────────────────►
  │  [Low Visibility]           │  [Content Strong]
낮음 │  • 지도 & 바이럴 모두 열세  │  • 바이럴은 활발하나
  │  • 전면적 마케팅 재정비     │  • 플레이스 순위 낙후
  │                             │
  └─────────────────────────────┴───────────────────────────────
             낮음                              높음          콘텐츠 점유율 (X축)
```

1. **사분면 포지션 분류**:
   - **Market Leader (플레이스 높음, 콘텐츠 높음)**: 지역 내 온/오프라인 환자 유입을 독점하는 최상위 병원.
   - **Local Strong (플레이스 높음, 콘텐츠 낮음)**: 지도 검색은 우수하나 바이럴 콘텐츠가 부족하여 의사결정 단계에서 이탈 발생.
   - **Content Strong (플레이스 낮음, 콘텐츠 높음)**: 바이럴 홍보는 활발하나 지도 플레이스 순위가 낮아 실제 길찾기/전화 예약 전환율 저하.
   - **Low Visibility (플레이스 낮음, 콘텐츠 낮음)**: 플레이스와 콘텐츠 모두 경쟁사에 밀려있는 상태.

2. **현재 포지션 진단 카드 (예시: 청주필한방병원)**:
   - **포지션 명칭**: **`LOCAL STRONG`**
   - **진단 해설**: *"플레이스 검색 경쟁력(72%)은 우수하지만, 블로그·웹문서·제3자 언급 영역의 콘텐츠 장악력(41%)이 상대적으로 부족합니다."*
   - **Recommended Action (실행 가이드)**:
     - `플레이스 유지` ➔ `콘텐츠 점유 확대` ➔ `제3자 언급(리얼 후기) 확대`

## 5. 기대 효과 및 컨설팅 활용 가치

1. **직관적인 병원장 설득력**:
   - "블로그 글은 많은데 왜 신환이 안 늘지?" ➔ *"플레이스 순위(72 vs 51)가 낮아 예약으로 연결되지 않기 때문입니다."*
   - "플레이스에는 나오는데 왜 검색하면 경쟁병원 글만 보이지?" ➔ *"콘텐츠 점유율(41 vs 72)이 열세여서 최종 선택에서 밀리고 있습니다."*
2. **명확한 예산 배분 가이드**:
   - 플레이스 중심 예산 투입 vs 바이럴 콘텐츠 제작 예산 투입의 우선순위를 데이터 기반으로 명쾌하게 제시.

## 6. 콘텐츠 바이럴 점유율 산출 기준

- **분석 결과 (Total Scan)**: 측정 키워드(질문셋) 1개당 상위 10개의 통합 검색 결과 문서를 스캔합니다. (예: 15개 키워드 × 10건 = 총 150건의 웹문서/블로그 데이터를 수집 및 분석)
- **자사 관련 (Our Contents)**: 스캔 데이터 중에서, 귀 병원(설정된 동의어 포함)의 공식 콘텐츠이거나 본문 내에 귀 병원 이름이 직접 '언급'된 콘텐츠들의 합산 개수입니다.
- **경쟁병원 관련 (Competitor Contents)**: 스캔 데이터 중에서 시스템에 등록해둔 '경쟁병원'들의 이름이 언급된 콘텐츠 개수입니다.
- **제3자 언급 (Third Party)**: 귀 병원도 아니고 경쟁병원도 아닌, 제3자(일반 정보성 글, 타 지역 병원 등) 콘텐츠의 개수입니다. `계산식 = 전체 분석 결과 - 자사 관련 - 경쟁병원 관련`

## 7. 질문셋과 네이버 검색어 간 1:1 순서(Index) 기반 매핑 파이프라인

네이버 플레이스 API는 단축 질의어(`naver_queries`, 예: `"청주 허리디스크 한방병원"`)를 사용하고, AI 가시성 진단 및 웹 크롤링은 자연어 질문셋(`queries`, 예: `"청주에서 허리디스크 치료 잘하는 한방병원 어디야?"`)을 사용합니다. 

두 질의어의 문자열 차이로 인한 매칭 오류를 방지하기 위해 다음과 같은 **4단계 다중 매핑 파이프라인**을 적용합니다:

1. **1순위 (직접 일치)**: `wa.query === a.query`
2. **2순위 (질문 배열 인덱스 매핑)**: `queries` 배열에서 인덱스 `idx`를 추출한 후 `naver_queries[idx]`와 `wa.query` 일치 여부 판정
3. **3순위 (동일 인덱스 1:1 매칭)**: `naverWebAnswers[idx]` 직접 대입
4. **4순위 (리스트 순회 Fallback)**: 화면 렌더링 순번에 따른 `naverWebAnswers[renderIdx]` 매핑

➔ 이를 통해 상단 종합 점수(예: 80%)와 하단 질문별 노출/미노출 리스트가 100% 일치하도록 보장합니다.

# 04. 웹 UI 실측 및 교차 비교 분석 (Web Verification & Comparison)

## 📌 개요
API를 통해 수집된 답변과 실제 사용자가 웹 브라우저에서 검색했을 때의 결과(Python Playwright 크롤링 엔진 `api_server.py`)를 1:1로 대조하고, 노출 격차와 차이 사유를 정밀 분석하는 화면입니다.

---

## 🎯 주요 기능 및 개선 사항 (v1.1.0)

### 1. 회차(Run ID) 선택 시 실측 AI 자동 체크
- 회차 셀렉터에서 특정 회차를 선택하면, **해당 회차에 실제로 데이터가 수집된 AI 플랫폼(ChatGPT, Gemini, Perplexity, Naver, Claude)만 체크박스에 자동으로 선택**됩니다.

### 2. 세션 저장형 브라우저 및 AI 사전 로그인 연동 (`api_server.py`)
- **영구 세션 저장 (`user_data`)**: Playwright의 `launch_persistent_context`를 사용하여 로그인 쿠키 및 세션을 보존, 비로그인 차단("가입 후 이용해주세요")을 원천 해결.
- **Perplexity Cloudflare 봇 차단(Turnstile) 완전 우회**:
  - 실물 Chrome 브라우저(`channel="chrome"`) 기반 WebGPU/WebGL 하드웨어 가속 플래그(`--use-gl=angle`, `--enable-webgl`) 탑재.
  - 불필요한 위장 JS 스크립트를 제거하고 자동화 변수(`cdc_`) 제거만 정밀 적용하여 Turnstile 체크박스를 100% 무사 통과.
- **비상 우회용 구글 연동 로그인 (`mode=google`)**:
  - 봇 차단 시 구글 OAuth 계정을 경유하여 Perplexity 세션을 자동 획득하는 비상용 연동 흐름 지원 (`↳ 우회용: 구글 연동 로그인`).

### 3. 전체 질문 순차 자동 실측 1:1 완전 동기화 (`WebVerificationModal.tsx`)
- 이전 질문의 크롤링 완료 및 브라우저 창 닫힘(`context.close()`)을 **`await`로 100% 보장한 후 다음 질문 창을 순차 실행**.
- 브라우저가 탭으로 끼어들거나 프로필 디렉토리 락(500 에러)이 발생하는 현상을 완벽히 방지.

### 4. UI 레이아웃 최적화
- **`전체 내장 창 일괄 닫기` & `닫기` 버튼 우측 상단 배치**:
  - 상단 액션바 오른쪽 끝(`ml-auto`)에 `[🛑 전체 내장 창 일괄 닫기]`와 `[닫기]` 버튼을 나란히 배치.
- **`API검색결과 / 메모` 컬럼 너비 1.5배 확장 (`w-96 min-w-[380px]`)**:
  - 긴 텍스트와 메모를 시원하게 열람할 수 있도록 테이블 컬럼 폭을 대폭 확장.

### 5. Gemini / Claude 웹 UI 질문 자동 입력 및 전송 로직
- URL 파라미터로 쿼리 전달이 지원되지 않는 플랫폼(Gemini, Claude)의 경우:
  - Playwright가 페이지 로드 후 `div[contenteditable="true"]`, `rich-textarea`, `div[role="textbox"]` 등 입력창을 자동 감지
  - 질문 텍스트 타이핑(`keyboard.type`) 후 Enter 전송 및 전송 버튼 클릭을 자동으로 수행하여 정상적인 AI 답변 수집 지원.

## 🖍️ 병원 고유 별칭 정밀 하이라이트 (Highlighting)

### 1. 일반 명사 단독 오탐 제거
기존에 "병원", "한방", "의원", "치료" 같은 일반 명사 단독 단어까지 노란색 형광펜으로 칠해져 화면이 산만해지던 현상을 완전히 제거하였습니다.

```typescript
const GENERIC_EXCLUDE_WORDS = new Set([
  '병원', '의원', '한방병원', '한의원', '한방', '센터', '클리닉', '의료원', '진료', '치료'
]);
```

### 2. 고유 브랜드/별칭 선별 매칭
- **`청주필한방병원`**, **`필한방병원`**, **`청주필한방`**, **`청주필`**, **`필한방`** 등 병원의 고유 브랜드명이 온전히 포함된 복합 별칭만 정확하게 형광펜(`mark`) 처리됩니다.

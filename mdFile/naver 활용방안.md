# 네이버(Naver) AI 가시성 진단 데이터 비교 분석 및 전략적 활용 방안

---

## 1. 개요: 네이버 API Hub 결과 vs 웹 UI 크롤링 결과의 차이

서울에이스병원(Run #46) 실측 결과, 네이버 채널에서 **API Hub(지역검색)** 결과와 **웹 UI 실측 크롤링** 결과 간에 명확한 차이가 발생하였습니다.

| 구분 | 네이버 API Hub (지역검색 Open API) | 웹 UI 실측 크롤링 (`search.naver.com`) |
|---|---|---|
| **데이터 소스** | **네이버 스마트플레이스 / 지도 DB** | **네이버 통합검색 (블로그, 카페, 지식iN, 웹문서, 파워링크)** |
| **작동 메커니즘** | 추출된 핵심 엔티티(`남양주 인공관절 정형외과`)로 지도 등록 병원 상위 5건 조회 | 전체 자연어 질문으로 통합검색 후 웹페이지 텍스트 전체 스캔 |
| **Run #46 결과** | **12개 질문 전체 ❌ 미노출 (0%)** | **12개 중 5개 질문 ✔️ 노출 (41.7%)** (Q02, Q04, Q07, Q08, Q12) |
| **노출/미노출 원인** | 플레이스 상위 랭킹(SEO)에 진입하지 못함 | 병원이 배포한 **블로그/바이럴/웹문서 스니펫**에 병원명이 걸려 노출됨 |

```
[데이터 파이프라인 비교]
1) API Hub: 질문 -> 엔티티 추출 -> [네이버 플레이스/지도 DB] -> 상위 5개 업체 (병원 등록 순위)
2) 웹 크롤링: 질문 -> 통합검색 -> [블로그/카페/웹문서/지식iN] -> 전체 텍스트 스캔 (콘텐츠 노출)
```

## 2. 데이터 활용 여부 진단

### 💡 결론: **"제외하지 않고, '플레이스 vs 바이럴 콘텐츠'로 분리하여 컨설팅 핵심 무기로 활용"**

1. **국내 시장 특수성 (네이버 점유율):**
   - ChatGPT, Gemini, Perplexity는 '문맥 기반 생성형 AI'이지만, 국내 의료 소비자의 60% 이상은 여전히 네이버를 통해 병원을 탐색합니다.
   - 따라서 네이버 데이터를 완전히 배제하면 한국 병원 대상 마케팅 진단 리포트의 현실성이 떨어집니다.

2. **컨설팅 인사이트 극대화 (가장 강력한 셀링 포인트):**
   - **서울에이스병원 진단 사례:**
     > *"원장님, 우리 병원은 블로그/바이럴 등 콘텐츠 작업이 잘 되어 있어 일반 검색 시 41.7% 노출되지만, 환자들이 실제로 전화하고 예약하는 **네이버 스마트플레이스 순위(API 기준 0%)**에서는 밀려나 있어 예약 전환율이 급감하고 있습니다."*
   - 이처럼 **'콘텐츠 노출(웹)'과 '지도 플레이스 노출(API)'의 괴리**는 병원 원장 및 마케팅팀에게 가장 즉각적이고 설득력 있는 개선 과제(Action Item)를 제시합니다.

## 3. 3가지 전략적 방향성 및 권장안

### 🥇 [권장] 방향 A: "네이버 하이브리드 교차 지표" 분리 리포팅
* **지표 구성:**
  1. **생성형 AI 3사 (ChatGPT / Gemini / Perplexity):** 순수 생성형 AI 챗봇 추천 점유율
  2. **네이버 로컬 가시성 (Naver Dual):**
     - **플레이스 점유율 (API):** 지도 상위 노출 여부 측정 (플레이스 최적화 지표)
     - **콘텐츠 바이럴 점유율 (웹 크롤링):** 블로그/웹문서 점유율 측정 (바이럴 마케팅 지표)
* **장점:** 두 데이터 간의 차이를 시스템 오차가 아닌 **'플레이스 SEO vs 바이럴 마케팅'의 입체적 비교 분석 데이터**로 승화시킴.

### 🥈 방향 B: 웹 크롤링 실측값으로 API 미노출 보정 (현재 모달 방식)
* API에서 미노출되었더라도 웹 실측에서 환자 화면에 실제 노출된다면 **'최종 노출(웹 실측 기준)'**으로 보정 반영.
* **장점:** 실제 검색 사용자가 보는 브라우저 화면 기준의 현실적인 노출률 반영.

### 🥉 방향 C: 네이버 채널을 진단에서 제외하고 생성형 AI에만 집중
* 네이버는 순수 LLM이 아니므로 지표에서 배제.
* **단점:** 국내 병원이 가장 중요시하는 네이버 검색 데이터를 놓치게 되어 리포트 활용도 저하.

## 4. 권장 액션 가이드

1. **리포트 라벨링 명확화:**
   - 네이버 영역에 한하여 *"네이버 지도 플레이스 기준(API) vs 네이버 통합검색 콘텐츠 기준(웹 실측)"* 명칭을 명확히 표기.
2. **웹 실측 결과 보존:**
   - `[웹 실측 DB 저장 & 교차 분석 리포트]` 기능을 활용하여 크롤링된 블로그/웹문서 원문 근거 데이터를 Supabase에 영구 보관하고 리포트에 증빙 자료로 첨부.
3. **병원 맞춤형 솔루션 제안:**
   - API 미노출 + 웹 실측 노출 병원 ➡️ **"스마트플레이스 최적화(SEO) 및 리뷰 활성화 집중 컨설팅"** 제안.
   - API 노출 + 웹 실측 미노출 병원 ➡️ **"블로그/지식iN 바이럴 콘텐츠 확충 컨설팅"** 제안.
